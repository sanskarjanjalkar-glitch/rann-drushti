RANN-DRUSHTI Architecture & Database Schema

Entity-Relationship & State Management Architecture for ATMS

1. System Flow & RBAC Architecture

RANN-DRUSHTI operates on a dual-portal architecture separating Administrative / Directive Command (Major/Colonel grade instructors) from Tactical Execution (Cadet / Officer Trainee). The system uses strict Role-Based Access Control (RBAC) ensuring instructors can author tests, monitor 6-member squad rosters in real-time, and dispatch off-platform physical tasks, while trainees receive synchronized timers, instant feedback, and verification workflows.

2. Relational Database Schema (PostgreSQL / SQLite Equivalent)

TABLE: users
  • • id: UUID (PK)
  • • service_number: VARCHAR(32) UNIQUE
  • • full_name: VARCHAR(128)
  • • rank: VARCHAR(32)
  • • role: ENUM('INSTRUCTOR', 'TRAINEE')
  • • squad_id: UUID (FK -> squads.id)
  • • created_at: TIMESTAMP
TABLE: squads
  • • id: UUID (PK)
  • • squad_name: VARCHAR(64) ('Alfa-6', 'Bravo-6')
  • • cohort_code: VARCHAR(32)
  • • max_capacity: INT DEFAULT 6
  • • instructor_id: UUID (FK -> users.id)
  • • created_at: TIMESTAMP
TABLE: questions
  • • id: UUID (PK)
  • • prompt: TEXT
  • • options: JSONB (A, B, C, D)
  • • correct_option: CHAR(1) ('A','B','C','D')
  • • difficulty: ENUM('Basic', 'Intermediate', 'Advanced')
  • • tactical_domain: VARCHAR(64)
  • • explanation: TEXT
TABLE: field_tasks & submissions
  • • id: UUID (PK)
  • • title, objective, target_grid: TEXT
  • • mode: ENUM('Single-User', 'Multi-User')
  • • trainee_id: UUID (FK -> users.id)
  • • verification_notes: TEXT
  • • status: ENUM('NOT_STARTED','ACTIVE','VERIFIED')
